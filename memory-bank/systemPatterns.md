# System Patterns

Describe architecture, major modules, data flow, APIs, integration points, and recurring implementation patterns.

## Event Taxonomy (versioned, codegen'd, type-gated)

The product's analytics + commission-relevant events are defined in a single
versioned source-of-truth file and codegen'd into strongly-typed PHP DTOs.
This pattern enforces "you cannot ship code that emits an event missing a
required field" as a CI-blocking type error rather than a runtime hope.

**Source of truth.**
`backend/config/events/taxonomy.v1.json` — one object per event:

- `name` (StudlyCase PHP class name)
- `slug` (snake_case wire-format name)
- `description`
- `fields[]` — each with `name`, `type` (`string|int|bool|iso8601`),
  `required`, optional `doc`

**Generated output.**
`backend/app/Events/Taxonomy/<EventName>.php` — one `final readonly class`
per event, extending the hand-written `BaseEvent`. Required taxonomy fields
become constructor parameters with no default value; optional fields become
`?type = null`. Each file is header-stamped `AUTOGENERATED ... DO NOT EDIT`.

**Codegen entry point.**
`backend/scripts/codegen-events.php`

- `php scripts/codegen-events.php`           — write generated classes
- `php scripts/codegen-events.php --check`   — exit 1 on drift (CI gate)

**Why this is the gate.**
Because required fields are non-defaulted ctor parameters, omitting one is:

1. an `ArgumentCountError` at runtime, and
2. a PHPStan `argument.missing` error at static-analysis time.

CI runs PHPStan (with Larastan) over `app/` and `tests/Static/`, so any new
call site that constructs `UpgradeCompleted(...)` without `placement_id`, or
`AffiliateLinkClicked(...)` without `affiliate_id`, fails CI before merge.

**Changing the taxonomy.**

1. Edit `backend/config/events/taxonomy.v1.json`.
2. Run `php scripts/codegen-events.php` (no `--check`) to regenerate.
3. Commit the JSON edit AND the regenerated `app/Events/Taxonomy/*.php`.

Bump to `taxonomy.v2.json` (new file, side-by-side) only for a true breaking
change that the consumers must opt into; bump the `version` field for
additive changes.

**Test coverage.**
`backend/tests/Unit/EventTaxonomy/`

- `CodegenDriftTest` — equivalent of `--check`, runs from `phpunit`.
- `RuntimeTypeGateTest` — reflection-asserts that required fields have no
  default and accept-no-null types; instantiates each event without each
  required field and confirms `ArgumentCountError` fires.
- `StaticGateTest` — invokes PHPStan against `tests/StaticGate/Fixtures/`
  (an intentionally-broken file NOT in the main analyse path) and asserts
  the analyser reports `argument.missing` for `placement_id` and
  `affiliate_id`.
